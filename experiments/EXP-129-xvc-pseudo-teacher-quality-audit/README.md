# EXP-129: X-VC pseudo-teacher quality audit

Status: prepared; diagnostic for the next training method

EXP-116 and EXP-124 teach the adapter to imitate full waveforms generated by
the frozen base X-VC. Before another source-pool change, transcribe every exact
pseudo-teacher waveform and its own materialized source reference. Report
source-relative distance and gross repetition by corpus, plus exact target and
teacher IDs. The existing outputs are reused; this job performs no conversion
or retraining.

This answers whether corrupt pseudo-targets are being distilled. It does not
score naturalness, target voice, or speaker similarity. The report may justify
one precommitted quality-routing method; it may not be used to declare a model
winner or to tune a threshold against downstream evaluation failures.
