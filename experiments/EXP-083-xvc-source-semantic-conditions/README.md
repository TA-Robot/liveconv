# EXP-083: source-semantic on frozen conditions

Status: completed; promising technical signal; operator hearing deferred

Render `--candidate-kind source-semantic` on EXP-033's ten clean, noise,
leading-silence, pitch, and tempo rows against EXP-035. Machine screen is
corruption/content only.

The candidate produced three wins, seven ties, and no losses. Macro
source-relative distance improved from `0.153` to `0.075`; the single noise row
improved from `0.375` to `0.000`, leading silence from `0.400` to `0.267`, and
the six clean rows from `0.084` to `0.039`. These one-row limitations are too
small for a robustness claim, so a multi-speaker stress matrix is required.
